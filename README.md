# Magische Belohnungen 🪄

Ein privates Familien-Belohnungsspiel: Kinder sammeln Aufgaben-Punkte und tauschen sie gegen Harry-Potter-Sammelkarten, magische Packs und ein animiertes Sammelalbum.

## Technisches

- Einfache HTML/PWA-Anwendung, die komplett im Browser läuft (Service Worker für Offline-Nutzung)
- Spielstände liegen im localStorage des Geräts – Sicherung über den Elternbereich (Export/Import)
- Kein Server, keine Datenübertragung an Dritte
